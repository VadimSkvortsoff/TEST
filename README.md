# Wishfall — симулятор круток Genshin Impact

Неофициальный фанатский симулятор молитв Genshin Impact. Это статический сайт: HTML, CSS и JavaScript, без сборки и сервера.

## Запуск локально

Откройте `index.html` в браузере.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. После завершения публикации GitHub покажет адрес сайта в этом разделе.

## Возможности

- Баннеры персонажа, оружия и стандартной молитвы.
- Одиночная и десятикратная крутка.
- Симуляция редкости 3★/4★/5★ и счётчики гаранта.
- История последних выпадений.
- Сохранение ресурсов и прогресса в `localStorage` браузера.

**Важно:** это фанатская симуляция с условными шансами. Она не связана с HoYoverse и не подключается к аккаунтам Genshin Impact.
